## Project
Smart Campus room availability checker using React, TypeScript and Vite. The application uses fictional room data and a fixed current time.

## Constraints
Preserve AC1–AC6 and the existing UI.
Do not add a backend, database, login or booking creation.
Keep the existing room fixtures unchanged.

## Engineering rules
Prefer pure functions and minimal changes.
Use at most two justified design patterns.
Do not mutate booking fixtures.
Keep existing validation messages and responsive UI feedback.
Avoid unnecessary abstractions and class hierarchies.

## Verification
Run existing tests and add focused regression tests when needed.
Run typecheck and build using the available project scripts.
Report changed files, rationale, test commands and actual results.
